IT-TICKET-ANALYSIS

Using Excel, I analyzed 97,498 tickets handled by 50 agents from 2016 to 2020. This project uncovered trends in resolution time, agent performance, customer satisfaction, and process inefficiencies — enabling data-driven decisions for better service delivery.

𝐊𝐄𝐘 𝐈𝐍𝐒𝐈𝐆𝐇𝐓𝐒: -Identified departments with long resolution times — helped prioritize training and resources -Highlighted top-performing agents using satisfaction scores and resolution speed -Detected mismatches between ticket priority and severity — shows gaps in triage accuracy -Observed rising ticket volumes post-2019 — indicates growing IT support demands -Found majority of issues in hardware and system-related categories -Login access issues resolved fastest but underutilized — opportunity for better routing

𝐃𝐀𝐒𝐇𝐁𝐎𝐀𝐑𝐃 𝐅𝐄𝐀𝐓𝐔𝐑𝐄𝐒: ▪️ Agent-wise performance tracker ▪️ Monthly trends of satisfaction rate and resolution time ▪️ Request category vs. resolution time comparison ▪️ Charts for severity, priority, and ticket categories ▪️ Interactive filters: year, category, priority, severity ▪️ Age-group analysis for satisfaction & resolution time
